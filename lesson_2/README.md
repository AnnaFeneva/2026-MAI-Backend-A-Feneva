# Лабораторная работа 2 — Nginx + Gunicorn + WSGI

Выполнено тестирование производительности с помощью ApacheBench (`ab`).  

Все тесты проводились на Windows, локальный сервер `localhost:8080`.

## Таблица тестов

| Локация       | Total Requests (-n) | Concurrency (-c) | Requests per second (RPS) | Failed Requests | Примечания |
|---------------|------------------|-----------------|---------------------------|----------------|------------|
| /public/test.png | 10000             | 1000             | 18764.82             | 0              | Статический файл, все запросы обработаны успешно |
| /public/test.png | 10000             | 1100             | 18846.41             | 192            | Появились первые ошибки при увеличении нагрузки на 10% |
| /gunicorn/       | 10000             | 500              | 77.99                | 0              | WSGI-приложение через Nginx, нагрузка без ошибок |
| /gunicorn/       | 10000             | 550              | 25                   | 1+             | Появились первые failed requests при +10% Concurrency |
| WSGI прямой      | 10000             | 2000             |78.14                 | 0              | Прямой доступ к Gunicorn без Nginx |
| WSGI прямой      | 10000             | 2200             | -                     1443      'w      | Failed requests появляются при увеличении на 10% |

> **Примечание:**  
> На Windows нельзя выставлять очень высокий уровень параллельных соединений (`-c`) из-за ограничений ОС. Значения выше 5000–10000 часто приводят к ошибкам соединений.
